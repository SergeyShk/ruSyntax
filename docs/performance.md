# Сравнение

От сырого текста ruSyntax точнее всех сравниваемых анализаторов на трибанках Taiga, GSD и Poetry и идет вровень со Stanza на PUD; на SynTagRus впереди Stanza - ее модели обучены на SynTagRus, а ruSyntax его не видел ([модель](model.md)). При этом ruSyntax разбирает около 30 тыс. слов в секунду в один поток вместе с морфологией ruMorph - в 2,8 раза быстрее spaCy, в 27 раз быстрее Stanza и в 69 раз быстрее Stanza на трансформере, - а загружается за 0,08 с.

## Качество { #quality }

Эталон - тестовые части трибанков [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus), [UD_Russian-Taiga](https://github.com/UniversalDependencies/UD_Russian-Taiga), [UD_Russian-GSD](https://github.com/UniversalDependencies/UD_Russian-GSD), [UD_Russian-PUD](https://github.com/UniversalDependencies/UD_Russian-PUD) и [UD_Russian-Poetry](https://github.com/UniversalDependencies/UD_Russian-Poetry) из релиза UD 2.19. Метрики - официального скрипта CoNLL 2018: UAS - доля слов с верной вершиной, LAS - с верными вершиной и типом связи (без подтипа); знаки препинания считаются. Соглашения разметки у трибанков разные, поэтому сравнивать стоит системы на одном наборе, а не наборы между собой.

На чем обучены модели: ruSyntax - Taiga, GSD и Poetry; Stanza и Stanza accurate (с трансформером rubert-base-cased) - SynTagRus из UD 2.18, и его тестовая часть для них своя; spaCy ru_core_news_sm и Slovnet - Nerus, новости, размеченные автоматически; UDPipe 1 - SynTagRus из UD 2.5, соглашения меток которого с тех пор поменялись, поэтому его LAS занижен сильнее UAS.

## Скорость { #speed }

Разбор эталонных токенов SynTagRus test (157 706 слов) в один поток, лучший из двух прогонов без загрузки; у ruSyntax - вместе с тегами ruMorph. Загрузка - импорт и создание анализатора с разбором первого предложения; память - пик процесса.

| Система | Слов/с | Загрузка, с | Память, МБ |
| :------ | -----: | ----------: | ---------: |
| ruSyntax | 29 526 | **0,08** | **160** |
| spaCy ru_core_news_sm | 10 368 | 2,00 | 1 007 |
| UDPipe 1 | 6 318 | 1,73 | 467 |
| Stanza | 1 098 | 2,84 | 6 638 |
| Stanza accurate | 428 | 4,66 | 5 993 |
| Slovnet (Natasha) | 58 583 | 0,27 | 360 |

Slovnet быстрее, но выбирает вершины без дерева, не дает морфологии и отстает по LAS на 5-31 пункт. Stanza accurate мерилась на первых 20 006 словах. Пик памяти зависит от объема текста за вызов: все системы, кроме Stanza accurate, получали весь SynTagRus test одним вызовом, поэтому ее пик с остальными не сравнивается. Замер - Apple M3 Pro, Python 3.11, load average 2-3.

## Как воспроизвести { #reproduce }

Скрипт `scripts/compare.py` скачивает тестовые части трибанков, скрипт оценки CoNLL 2018 и модели аналогов с проверкой SHA-256 (модели Stanza - ее загрузчиком с проверкой сумм файлов), разбирает наборы каждой системой и считает метрики, а скорость, загрузку и память меряет в отдельном процессе на систему, и пишет таблицы. Версии пакетов закреплены в `scripts/compare.py.lock`; ruSyntax берется из колеса, собранного из репозитория, а ruMorph и anySeg закрепляются в команде (их версии пишутся в результаты):

``` bash
rm -rf target/compare/wheels
uvx maturin@1.15.0 build --release --locked -o target/compare/wheels
uvx uv@0.13.5 run --with target/compare/wheels/rusyntax-*.whl --with rumorph==0.7.0 --with anyseg==0.5.0 \
    scripts/compare.py target/compare
```
